BANCO

Por padrão, no seu config.py, usamos SQLite:

python
SQLALCHEMY_DATABASE_URI = os.environ.get('DATABASE_URL', 'sqlite:///site.db')
Ou seja, se você não configurar outra URI no .env, o banco será um arquivo site.db dentro da pasta instance/.

👉 Vantagem: simples, roda local sem precisar instalar nada.
👉 Em produção: pode trocar para Postgres ou MySQL apenas alterando a variável DATABASE_URL no .env.

----
SQL Injection: protegido, porque usamos SQLAlchemy ORM (não concatenamos strings).

Senhas: armazenadas com hash seguro (generate_password_hash → PBKDF2).

Campos extras: ajudam a mitigar brute force (bloqueio de conta).

Criptografia do banco: SQLite não criptografa por padrão. Em produção, ideal usar Postgres/MySQL com criptografia em disco.

APLICAR MUDANÇA BANCO DE DADOS 
🔹 Como alterar (quando muda o modelo)
Exemplo: adicionamos failed_attempts e is_locked.

Gerar nova migration:

bash
flask db migrate -m "add security fields to User"
Aplicar:

bash
flask db upgrade
------------
🔹 Como criar o banco
Inicializar migrations (se ainda não fez):

bash
flask db init
Criar migration:

bash
flask db migrate -m "create user table"
Aplicar migration:

bash
flask db upgrade
Isso cria o arquivo site.db com a tabela User.
